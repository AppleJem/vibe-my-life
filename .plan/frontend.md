## Routing — TanStack Router (File-Based)

### Route Structure

```
frontend/src/
├── routes/
│   ├── __root.tsx           # Root layout (wraps all routes)
│   ├── login.tsx            # /login (public)
│   ├── _authenticated.tsx   # Pathless layout (auth guard)
│   └── _authenticated/
│       └── index.tsx        # / (dashboard, protected)
├── routeTree.gen.ts         # Auto-generated by TanStack plugin
```

### How It Works

- **`__root.tsx`**: Root layout with `<Outlet />`, global elements (e.g., toast container)
- **`login.tsx`**: Public route, renders login page
- **`_authenticated.tsx`**: Pathless layout route with `beforeLoad` auth check — redirects to `/login` if no JWT
- **`_authenticated/index.tsx`**: Dashboard page, nested under auth guard

### Auth Protection

```typescript
// routes/_authenticated.tsx
import { createFileRoute, redirect, Outlet } from '@tanstack/react-router'

export const Route = createFileRoute('/_authenticated')({
  beforeLoad: ({ location }) => {
    const token = localStorage.getItem('token')
    if (!token) {
      throw redirect({
        to: '/login',
        search: { redirect: location.href },
      })
    }
  },
  component: () => <Outlet />,
})
```

## Pages

### LoginPage (`routes/login.tsx`)
- Centered card with username/password inputs
- Candy-pink gradient submit button
- Error message display on failed login
- On success: store JWT in localStorage, redirect to `/` (or search.redirect)

### DashboardPage (`routes/_authenticated/index.tsx`)
- `Layout` wrapper with header
- `MonthHeader` — current month display with ← → arrows
- `ExpenseList` — scrollable list of expenses for selected month
- `SwipeContainer` — wraps content, handles left/right swipe for month nav
- FAB (+) button — bottom right, opens `AddExpenseModal`

## Components

### Layout.tsx
- App header with "Vibe My Life" title
- Optional: settings/logout button
- Responsive container

### MonthHeader.tsx
- Displays: "August 2026" format
- Left arrow (←) / Right arrow (→) buttons
- Shows monthly total amount
- Receives `currentMonth` and `onMonthChange` props

### ExpenseList.tsx
- Renders list of `ExpenseItem` components
- Empty state: "No expenses this month" with emoji
- Loading state: skeleton/spinner

### ExpenseItem.tsx
- Shows: category emoji, note (or category name), amount, date
- **Swipe-to-delete**: swipe left reveals red delete zone
- On release past threshold → show confirm popup
- Confirm popup: "Delete this expense?" with Cancel/Delete buttons
- Spring animation on delete

### SwipeContainer.tsx
- Wraps the expense list content
- Uses `@use-gesture/react` `useDrag` for horizontal swipe detection
- Uses `@react-spring/web` for slide animation
- Swipe left → next month, swipe right → previous month
- **Free navigation** — no bounds on months

### AddExpenseModal.tsx
- Full-screen bottom-sheet modal (slides up)
- Multi-step flow with progress indicator
- Steps: Date → Amount → Category → Note
- Back button to return to previous step
- Cancel (X) button to close
- Submit button on final step

## Services

### api.ts
- Axios instance with base URL from env
- Request interceptor: attach JWT from localStorage
- Response interceptor: handle 401 → redirect to login
- Methods:
  - `login(username, password)` → stores token
  - `getExpenses(month)` → GET /api/expenses?month=YYYY-MM
  - `createExpense(data)` → POST /api/expenses
  - `updateExpense(id, data)` → PUT /api/expenses/:id
  - `deleteExpense(id)` → DELETE /api/expenses/:id
  - `logout()` → clear token

## Styling — Dark Candy Pop (Tailwind Colors)

### Color Mapping

Use Tailwind's built-in palette. No custom colors needed.

| Role | Tailwind Class | Usage |
|------|----------------|-------|
| Page background | `bg-zinc-950` | Main app background |
| Surface/Cards | `bg-zinc-900` | Cards, modals, list items |
| Elevated | `bg-zinc-800` | Inputs, hover states, calculator buttons |
| Primary (pink) | `rose-400` | FAB, CTAs, selected states, highlights |
| Accent (cyan) | `cyan-400` | Links, selected date, secondary highlights |
| Secondary (purple) | `violet-400` | Gradients, decorative accents |
| Positive | `lime-400` | Income indicators, success states |
| Warning | `amber-400` | Warnings, caution |
| Danger | `red-500` | Delete actions, errors |
| Primary text | `text-zinc-100` | Main text, headings |
| Secondary text | `text-zinc-400` | Muted text, labels, placeholders |
| Border | `border-zinc-800` | Subtle dividers |

### Visual Effects
- FAB: gradient (`from-rose-400 to-violet-400`), shadow glow (`shadow-rose-500/25`)
- Cards: glassmorphism (`bg-zinc-900/80 backdrop-blur-sm`)
- Modals: slide-up animation with `bg-zinc-900`
- Active/selected states: `ring-2 ring-rose-400` or solid `bg-cyan-400`
- Border radius: `rounded-2xl` for cards, `rounded-xl` for buttons/inputs
- Swipe transitions: spring animations via `@react-spring/web`
- Hover states: `hover:bg-zinc-800` for interactive elements
- Focus rings: `focus:ring-2 focus:ring-rose-400` for accessibility
