# Vibe My Life — Expense Tracker Plan

## Overview

A personal full-stack web app for tracking expenses. Mobile-first, dark mode with candy pop colors. Single user (you). Designed to be extensible for future features (notes, calendar, AI automation).

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React, TypeScript, Vite, TailwindCSS |
| Routing | TanStack Router (file-based) |
| Backend | Express, TypeScript |
| Database | DynamoDB (single table) |
| Package Manager | pnpm (monorepo) |
| Gestures | @use-gesture/react, @react-spring/web |

## Design Decisions

- **Monorepo**: pnpm workspaces with `frontend/` and `backend/`
- **Routing**: TanStack Router with file-based routing (auto-generated route tree)
- **Auth**: JWT-based, extensible strategy pattern (credentials now, Google later)
- **Auth guard**: Pathless layout route `_authenticated.tsx` with `beforeLoad` redirect
- **Table name**: `vibe-my-life-expense`
- **Month navigation**: Free (can go to any month, past or future)
- **Delete**: Swipe-to-delete with confirm popup
- **Calculator**: Simple expression builder (e.g., `12+5-3=` → `14`)
- **Date picker**: Custom calendar grid (not native picker)
- **Styling**: Tailwind built-in colors (zinc, rose, cyan, violet, lime, amber) — no custom hex values
- **Theme**: Dark mode candy pop using Tailwind's palette
